# Session Logs

One file per session: `YYYY-MM-DD_session-N.md` (N starts at 1 each day). Keep each log under about 50 lines. Logs record history; current state belongs in `PROGRESS.md`.

## Template
```markdown
# Session YYYY-MM-DD #N
**Objective:**
**Initial state:** (git HEAD or short description; open tasks)
**Tasks attempted:** TASK-NNN: outcome
**Important changes:** files and what changed
**Decisions:** DEC-NNN (or none)
**Errors:** ERR-NNN (or none)
**Validation:** commands run and results
**Current state:**
**Outstanding:**
**Next session starts at:** the exact file, function, or step, and the next action
```
